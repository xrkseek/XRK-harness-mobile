### 中文

**XRK Harness 手机版 0.7.16** — 本产品线 **App 首发**。

- 本机 proot 运行 `@xrkseek/harness-cli@0.7.16`（`xrkh`），也可连接电脑 / 服务器 Host
- 对话与桌面同源 Web 壳；含语音 / TTS
- 手机操控（授权后 `phone_*`）；可选访问手机文件（`/sdcard`）
- 应用内更新：同 Release 的 `update.json`
- 产品名：**XRK Harness**（致敬 DSH Go 工程路径）

### English

**XRK Harness Mobile 0.7.16** — **first App release** on this product line.

- On-device `@xrkseek/harness-cli@0.7.16` (`xrkh`) in proot, or a remote Host
- Chat UI shares the desktop web shell; voice / TTS
- Phone control (`phone_*` after permission); optional phone files at `/sdcard`
- In-app updates via `update.json` on this Release
- Product name: **XRK Harness** (with respect to the DSH Go engineering path)
